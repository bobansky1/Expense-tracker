# Траты — личный журнал расходов

React + TypeScript + Vite + Tailwind CSS + официальные компоненты shadcn/ui (Radix).

## Запуск

Требуется Node.js 22.18+ (проверено на Node.js 24).

```sh
npm ci
npm run dev -- --host 127.0.0.1
```

Откройте адрес, который напечатает Vite. Хранилище привязано к адресу, порту и браузеру: для повседневного использования запускайте приложение на одном адресе.

```sh
npm test
npm run build
npm run preview -- --host 127.0.0.1
```

Сборка для размещения: `dist/`.

## Что умеет приложение

- Добавление, изменение и удаление расходов в рублях: сумма, категория, дата, заметка.
- Итоги за выбранный месяц, сегодня и всё время; среднее по дням, в которые были расходы.
- График по дням и распределение по категориям.
- Таблица с поиском, фильтрами и группировкой по дням, категориям и месяцам.
- CSV для выбранных записей и JSON для полной резервной копии.
- Восстановление JSON с проверкой данных и подтверждением замены.
- Адаптивный интерфейс для компьютера и телефона.

## Хранение

Первая версия хранит записи в localStorage под ключом `expense-journal.v1`. Суммы — целые копейки; даты — календарные строки `YYYY-MM-DD`, без преобразования в UTC. Данные сохраняются после каждой операции. Повреждённые данные не перезаписываются автоматически. JSON содержит все записи; CSV учитывает месяц и фильтры.

Синхронизации между устройствами, авторизации и подключённой MySQL пока нет. Очистка данных браузера удалит журнал. Регулярно скачивайте JSON. Не редактируйте журнал одновременно в нескольких вкладках.

## Подключение MySQL следующим этапом

Архитектура: React → HTTPS API (Node.js + Express/Fastify) → MySQL.

1. Разместить сервер API и MySQL, создать отдельного пользователя БД с минимальными правами.
2. Добавить вход в аккаунт, серверные сессии в HttpOnly cookie и защиту запросов.
3. Применить `docs/mysql-schema.sql` после проверки версии MySQL и настроек миграций. Это заготовка схемы, не выполненная миграция.
4. Реализовать GET/POST/PATCH/DELETE `/api/expenses` с проверкой полей, параметризованными запросами и ограничением каждой операции текущим пользователем.
5. Заменить функции хранилища в `src/lib/expenses.ts` асинхронным API; добавить состояния загрузки, обработку ошибок и конфликтов в React.
6. Импортировать локальную JSON-копию через серверную проверку, подключить резервное копирование БД и HTTPS.

Пароли БД хранятся только на сервере в переменных окружения. Не добавляйте их в переменные `VITE_*` — они попадают в браузер. Сам домен не хранит данные: нужны хостинг приложения и сервер базы данных.

## Идеи развития

- Месячные лимиты по категориям и прогресс бюджета.
- Свои категории, регулярные платежи и подписки.
- Сравнение месяцев и изменение расходов в процентах.
- PWA: установка на телефон, офлайн-запись с последующей синхронизацией.
- Импорт банковских CSV с предпросмотром и защитой от дублей.

## UI

Компоненты находятся в `src/components/ui`. Они получены из реестра https://ui.shadcn.com через CLI. Общие стили — `src/index.css`, макет — `src/App.css`. `src/shadcn-tailwind.css` скопирован из пакета shadcn: CLI не требуется для запуска приложения.
